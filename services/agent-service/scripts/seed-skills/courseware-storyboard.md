# Courseware Storyboard

把课程设计成学习路径，而不是把文章切成幻灯片。默认产出内容与视觉分镜，不依赖特定绘图或课件服务。

## 工作流程

1. 定义学习者、先备知识和一个可观察的学习目标。
2. 做前测问题，识别学习者最可能的错误理解。
3. 将内容拆成 3–7 个认知台阶，每一步只引入一个新概念。
4. 为每一步设计“解释 → 示例 → 小练习 → 反馈”。
5. 把抽象关系转成白板元素：框、箭头、时间线、坐标、角色或对比。
6. 用结尾任务检验学习目标，而不是只问“听懂了吗”。

## 分镜格式

| 镜头 | 学习目的 | 讲解词 | 画面元素 | 出现顺序 | 互动 |
|---|---|---|---|---|---|

画面元素使用可执行描述，例如“左侧画三个输入框，箭头汇入右侧决策菱形”，不要只写“展示流程图”。

## 手绘风规则

- 每屏只突出一个关系。
- 使用粗线、简单形状和少量强调色。
- 先画结构，再逐步加入标签，避免一开始信息过载。
- 装饰图标必须帮助记忆或定位。

## 输出

提供课程概要、逐镜分镜、练习答案、讲师提示和需要补充的事实来源。对于用户未提供的专业事实，明确标记待核验。
