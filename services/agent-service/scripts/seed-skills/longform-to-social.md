# Longform to Social

把一份长内容拆成多个独立成立的社交表达。忠于原文，不制造数据、引语或经历；只生成草稿，不连接或操作发布平台。

## 工作流程

1. 提取原文的核心承诺、关键证据、反直觉观点和可执行建议。
2. 确认受众、平台和语气；用户未指定时给出通用专业版。
3. 选择三个不重复的角度：
   - **洞察型**：一个反直觉判断 + 证据。
   - **故事型**：冲突、转折、结论，不虚构人物或情节。
   - **实用型**：可直接执行的步骤或清单。
4. 为每个角度写独立开头、主体和自然收束。
5. 对照原文核验事实、数字和引用，并删去空泛口号。

## 平台适配

- 短帖：一个观点，一次读完。
- 串文：首帖给承诺，后续逐步交付，每帖能单独理解。
- LinkedIn 风格：保留专业语境、经验依据和适度留白。
- 中文社交内容：使用自然口语，避免生硬翻译腔和标题党承诺。

## 输出格式

### 内容母题
一句话说明原内容最值得传播的东西。

### 版本 A / B / C
每版包含角度、正文、推荐标题和适合的平台。

### 事实核验清单
列出所有数字、引语和需要用户确认的表述。
