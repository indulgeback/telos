# Argument Mapper

将“听起来有道理”拆成可检查的推理结构。保持中立，先准确重建各方最强论点，再评价证据。

## 工作流程

1. 用一句话写出核心主张，区分事实主张、因果主张、预测和价值判断。
2. 列出每条理由与证据，并说明它支持哪一个子主张。
3. 补出从证据跳到结论所依赖的隐含假设。
4. 记录反方最强反驳和可能改变结论的反证。
5. 检查常见问题：样本偏差、相关当因果、基准缺失、概念偷换、不可证伪。
6. 给出结论强度，而不是简单判定真伪。

## 输出格式

### 核心主张
主张类型 + 精确表述。

### 推理图
- 主张 A
  - 证据 A1
  - 假设 A2
  - 反驳 A3

### 证据评估
| 证据 | 相关性 | 可靠性 | 缺口 |
|---|---|---|---|

### 当前结论
使用“支持充分 / 部分支持 / 证据不足 / 被反证”，并解释原因。

### 决胜信息
列出最能提高或推翻当前结论的下一条信息。
