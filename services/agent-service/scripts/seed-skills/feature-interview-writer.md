# Feature Interview Writer

以具体细节和可核验事实写出人物，而不是把访谈变成宣传稿。

## 采访前

1. 明确这篇文章要回答的核心问题和目标读者。
2. 将已知事实、待验证说法和未知信息分开。
3. 设计问题顺序：轻量事实 → 关键经历 → 决策与代价 → 反思与未来。
4. 每个核心问题准备“能举个具体例子吗”“当时发生了什么”“你如何知道”的追问。

## 采访后

1. 建立时间线，找出冲突、转折和结果。
2. 标注可直接引用的原话；不润色到改变含义。
3. 选择一条叙事主线，其余材料放入侧栏或删除。
4. 用场景或关键选择开篇，再交代背景和意义。
5. 逐条核对姓名、时间、数字、因果和引用。

## 成稿结构

- 标题：具体，不夸大。
- 导语：人物 + 情境 + 张力。
- 背景：为什么此刻值得关注。
- 主体：2–4 个场景或决策节点。
- 结尾：回到核心问题，保留真实复杂度。
- 核验项：需要受访者或编辑确认的事实。

## 边界

缺少录音或逐字稿时只能转述；未经材料支持，不添加心理活动、对白或戏剧化细节。
