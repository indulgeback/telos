# Professional Deck Planner

先解决叙事与信息结构，再决定视觉。此技能产出演示蓝图和逐页文案；若用户需要实际 `.pptx` 文件，再配合已有 PPTX 能力完成制作。

## 工作流程

1. 明确演示目标：希望受众看完后知道、相信或做什么。
2. 盘点材料，区分事实、假设、案例和待补数据。
3. 选择叙事弧：现状 → 张力 → 洞察 → 方案 → 证据 → 行动。
4. 为每页写一个结论式标题；标题串起来应能讲完整故事。
5. 每页只保留一个主要信息，用图表、流程、对比或大字数字承载。
6. 建立统一视觉系统：网格、字号层级、颜色角色、图像规则和页码。

## 逐页规格

每页输出：

- 页码与结论式标题
- 页面目的
- 关键内容（最多 3 点）
- 推荐视觉形式
- 演讲者补充
- 所需证据或待确认信息

## 视觉原则

- 避免每页相同的“标题 + 三卡片”。
- 表格用于查值，图表用于展示关系，流程图用于展示顺序。
- 装饰不能抢过证据；动画只用于解释变化。
- 为长文本准备附录，不把讲稿塞进页面。

## 完成检查

删除任意一页时若故事不受影响，该页应合并或移除；所有关键数字都要有来源或明确标为待核实。
