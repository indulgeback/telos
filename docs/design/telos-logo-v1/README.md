# Telos Logo 01

Accepted direction: a growing T, with a broad slanted crown, a curved stem and a sage leaf inset. The symbol is redrawn as native SVG for clean small-size rendering.

## Assets

- `apps/web/public/brand/telos-01/mark.svg`: navy and sage primary mark, transparent background.
- `apps/web/public/brand/telos-01/mark-white.svg`: white monochrome mark for dark backgrounds.
- `apps/web/public/brand/telos-01/app-icon.svg`: white mark on a navy rounded square.
- `icon-32.png`, `icon-180.png`, `icon-512.png`: favicon, Apple touch icon and app preview exports.
- `mark-512.png`: transparent primary mark preview.

Colors: navy `#17262e`, sage `#708367`. The live wordmark uses Libre Baskerville with Georgia fallback. The symbol itself has no font dependency.

The shared TelosLogo and TelosMark components supply navigation, footer and dashboard rail branding. The SVG component inherits surrounding text color, preserving dark-theme contrast. Versioned icon URLs are registered in the root layout.

`concepts.png` retains the three-option exploration. `previous/` preserves copies of the old favicon and touch icon; original legacy assets also remain in public.
